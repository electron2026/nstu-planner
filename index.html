Установка и уведомления 📲

Установите ежедневник на главный экран — он будет открываться без интернета и напоминать о дедлайнах.

  1. Откройте сайт в Google Chrome или Яндексе.
  2. Нажмите на иконку «⋮» (Три точки) вверху браузера.
  3. Выберите «Установить приложение» или «Добавить на главный экран».
  4. Подтвердите установку — на рабочем столе появится иконка без адресной строки!
  1. Откройте сайт строго в стандартном браузере Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой ⬆️ внизу экрана).
  3. Пролистайте список и выберите «На экран „Домой“».
  4. Нажмите «Добавить» в правом верхнем углу.

1. Android (Chrome):
Нажмите «Разрешить и проверить уведомления» ниже. Если окна нет: значок замка слева от адреса → Разрешения → Уведомления: Разрешить. В настройках батареи разрешите фоновую работу для Chrome.

2. Xiaomi, Realme, OnePlus:
Настройки → Приложения → Chrome (или ярлык Планнера). Включите «Автозапуск», режим батареи — «Нет ограничений».

3. Samsung:
Настройки → Приложения → Chrome → Уведомления (разрешить всё). Батарея → убрать браузер из спящих.

4. iPhone (iOS 16.4+):
Уведомления работают только с рабочего стола. Откройте приложение с иконки и нажмите кнопку ниже, чтобы разрешить системные уведомления.
